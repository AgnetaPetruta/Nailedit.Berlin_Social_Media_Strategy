# Nailedit.Berlin Social Media Proposal

A static, one-page proposal by Agneta Camelia. No build tool or installation is needed.

## Publish with GitHub Pages

1. Create a new GitHub repository. Set it to **Public** if Olga should be able to open the link without signing in.
2. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, `script.js`, `.nojekyll`, and the `assets` folder at the top level.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to show the published URL. Open it on desktop and mobile before sending it to the client.

To preview locally, open `index.html` in a browser. Images, navigation, and styling are included in this package. The Poppins, DM Sans, and Space Grotesk typefaces load from Google Fonts when online, with system fallbacks when offline.
